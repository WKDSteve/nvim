Hier ist eine Übersicht der nützlichsten Tastenkombinationen für den Windows-Explorer, unterteilt nach Einsatzbereich:

## Navigation & Ordner wechseln

| Tastenkombination | Funktion |
| --- | --- |
| **Alt + Pfeil nach oben** | Einen Ordner-Ordner nach oben gehen (Übergeordneter Ordner) |
| **Alt + Pfeil nach links** | Zurück (zum vorherigen Ordner in der Chronologie) |
| **Alt + Pfeil nach rechts** | Vorwärts |
| **Strg + N** | Ein neues Explorer-Fenster mit demselben Pfad öffnen |
| **Strg + W** | Aktuelles Explorer-Fenster (oder Tab) schließen |
| **Strg + T** | Einen neuen Tab öffnen *(Windows 11)* |
| **Strg + Tab** / **Strg + Shift + Tab** | Zwischen den geöffneten Tabs wechseln *(Windows 11)* |

---

## Ansichten & Layouts steuern

| Tastenkombination | Funktion |
| --- | --- |
| **Alt + P** | Vorschaufenster ein- oder ausblenden |
| **Alt + Shift + P** | Detailbereich auf der rechten Seite ein- oder ausblenden |
| **Strg + Umschalt + 1 bis 8** | Ordneransicht ändern (z. B. `Strg + Shift + 2` = Große Symbole, `Strg + Shift + 6` = Details) |
| **Strg + Mausrad** | Symbolgröße im Ordner stufenlos anpassen |
| **F11** | Vollbildmodus aktivieren oder beenden |

---

## Dateien verwalten & Suchen

| Tastenkombination | Funktion |
| --- | --- |
| **Strg + Umschalt + N** | Direkt einen neuen Ordner erstellen |
| **F2** | Ausgewählte Datei umbenennen |
| **Entf** (Delete) | Ausgewählte Datei in den Papierkorb verschieben |
| **Shift + Entf** | Datei **endgültig löschen** (ohne Papierkorb) |
| **Alt + Enter** | Eigenschaften-Fenster der markierten Datei/des Ordners öffnen |
| **Strg + F** oder **F3** | Direkt ins Suchfeld springen |
| **Strg + L** oder **Alt + D** | Adresszeile markieren (um Pfad einzugeben oder zu kopieren) |

---

## Markieren & Auswählen

| Tastenkombination | Funktion |
| --- | --- |
| **Strg + A** | Alle Dateien und Ordner im aktuellen Pfad markieren |
| **Shift + Pfeiltasten** | Mehrere nebeneinanderliegende Dateien markieren |
| **Strg + Leertaste** | Einzelne Dateien gezielt an- oder abwählen (in Kombination mit den Pfeiltasten) |
