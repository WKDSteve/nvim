Hier ist die aktualisierte Tabelle für deine deutsche Tastatur mit US-Belegung in CMD:

## Sonderzeichen-Tabelle

| Zeichen | Tastenkombination |
| --- | --- |
| `:` | Shift + Ö |
| `;` | Shift + , |
| `*` | Shift + + |
| `/` | - |
| `\` | # |
| `?` | Shift + ß |
| `@` | Shift + 2 |
| `"` | Shift + Ä |
| `'` | Ä |
| `~` | Shift + ^ |
| `-` | ß |
| `_` | Shift + ß |
| `=` | ´ |
| `+` | Shift + ´ |
| `(` | Shift + 8 |
| `)` | Shift + 9 |
| `[` | Ü |
| `]` | + |
| `{` | AltGr + 7 |
| `}` | AltGr + 0 |
| `<` | Shift + `,` |
| `>` | Shift + `.` |
| \` | \` \| AltGr + \< |

Bestätigt `"` = Shift + Ä und `~` = Shift + ^

Hinweis: Die beiden bestätigten Kombinationen haben Vorrang. Bei den übrigen Zeichen können einzelne Zuordnungen je nach tatsächlich aktivem Layout abweichen.
